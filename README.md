# החתונה של עידו ותאיר: אתר + אישורי הגעה

| חלק | איפה | מה עושה |
|---|---|---|
| אתר החתונה | ריפו **wedding-site** (הריפו הזה) → Vercel | ההזמנה, Waze, יומן, טופס אישור הגעה |
| וואטסאפ | ריפו **wedding-site**, תיקייה `api/` → Vercel | שולח הזמנה עם כפתורים וקולט תשובות |
| שיחות AI | ריפו **wedding-call** → AI Studio / Cloud Run | מתקשר למי שלא ענה (Gemini Live + Twilio) |
| גיליון "מוזמנים לחתונה" | Google Drive | לשונית "אישורי הגעה" מהאתר + ה-Apps Script (המנוע) |
| גיליון "רשימת מוזמנים - חתונה עידו ותאיר" | Google Drive | לשוניות האורחים (לא משתנות) + לשונית **"סיכום אישורים"**: כל התשובות (אתר, וואטסאפ, שיחה) |

## ✅ מה כבר עובד
- האתר באוויר ב-Vercel, כולל טופס עם טלפון חובה ובחירת מנה.
- אישורים מהאתר נשמרים בלשונית "אישורי הגעה" (יש 2 אישורי ניסיון מ-19.11).
- רשימת המוזמנים הועתקה מהאקסל לגוגל שיטס: 11 לשוניות, 530 שורות, 343 עם טלפון.
- הקוד לוואטסאפ (כאן) ולשיחות (wedding-call, ענף `claude/secure-sheets`) כתוב ונבדק בהדמיה.

---

## 📋 מה נשאר, שלב אחרי שלב
סמנו `[x]` כשסיימתם. **אל תדלגו על שלבי הבדיקה**: שליחה אמיתית מגיעה לאורחים אמיתיים.

### שלב 1: ניקוי הנתונים (15 דקות)
- [ ] בגיליון "מוזמנים לחתונה" > לשונית "אישורי הגעה": למחוק את 2 שורות הניסיון (קליק ימני על מספר השורה > מחיקת שורה).
- [ ] ברשימת המוזמנים לתקן 3 מספרים:
  - מיטל דיקמן (חברות אמא חתן): `542-566649`, חסר 0 בהתחלה.
  - שרלי מרציאנו (משפחה אבא חתן): `054-588584`, חסרה ספרה.
  - עליזה אבו (משפחה אמא חתן): `08-6481558`, נייח. וואטסאפ לא יגיע, שיחה כן.
- [ ] להשלים טלפונים ל-187 השורות שחסרות (בעיקר הלשוניות של צד הכלה). בלי טלפון אין וואטסאפ ואין שיחה.
- [ ] ללשונית "חברים אחים כלה" עוד אין שמות.

### שלב 2: Apps Script (10 דקות)
1. [ ] לפתוח את הגיליון **"מוזמנים לחתונה"** > תוספים > Apps Script.
2. [ ] למחוק את הקוד הקיים ולהדביק את כל התוכן של [`rsvp-apps-script.gs`](rsvp-apps-script.gs). לשמור (Ctrl+S).
3. [ ] גלגל השיניים (Project Settings) > **Script Properties** > Add: שם `SECRET`, ערך: מחרוזת אקראית ארוכה (40 תווים). **לשמור אותה בצד**, צריך אותה בשלבים 3 ו-5.
4. [ ] בראש העורך לבחור את הפונקציה **`testGuests`** > **Run** > לאשר הרשאות (Advanced > Go to project).
   ב-Execution log צריך להופיע: `אורחים עם טלפון: 343` (או יותר, אחרי שלב 1).
5. [ ] **Deploy > Manage deployments > עיפרון > Version: New version > Deploy**. הכתובת נשארת אותה כתובת.
6. [ ] בדיקה: לפתוח בדפדפן את כתובת ה-`/exec` ובסופה `?name=בדיקה&phone=<הטלפון שלך>&attending=מגיע/ה&guests=1&diet=טבעוני`
   - צריך להופיע `ok: נשמר` (ואם הטלפון שלך ברשימה: `+ עודכן ברשימת המוזמנים`).
   - ברשימת המוזמנים, בלשונית **"סיכום אישורים"** (ראשונה משמאל), יש שורה לכל אורח עם סטטוס, כמות מאושרת, מנה וערוץ. לשוניות האורחים עצמן לא משתנות.
   - למחוק אחר כך את שורת הבדיקה מ"אישורי הגעה", ולנקות את הסטטוס בשורה שלך ברשימה.

### שלב 3: משתנים ב-Vercel לאתר (5 דקות)
1. [ ] Vercel > פרויקט wedding-site > **Settings > Environment Variables**:
   | שם | ערך |
   |---|---|
   | `ADMIN_KEY` | סיסמה שאתם בוחרים (להפעלת השליחה) |
   | `SHEET_URL` | כתובת ה-`/exec` |
   | `SHEET_SECRET` | ה-`SECRET` משלב 2.3 |
2. [ ] **Deployments > ⋯ > Redeploy**.
3. [ ] בדיקה: `https://<האתר>/api/send-whatsapp?key=<ADMIN_KEY>&dry=1` צריך להחזיר `wouldSend` עם רשימת שמות (לא שולח כלום).
4. [ ] לשלוח לי את כתובת האתר, ואעדכן את תמונת התצוגה המקדימה לוואטסאפ (`og:image`).

### שלב 4: וואטסאפ (שעה + עד יום לאישור התבנית)
1. [ ] לבצע את **שלב 2** ב-[`docs/rsvp-automation.md`](docs/rsvp-automation.md): אפליקציה ב-Meta, מספר, טוקן קבוע, תבנית `wedding_rsvp` עם 2 כפתורים (`מגיעים`, `לא נוכל להגיע`), Webhook ל-`https://<האתר>/api/whatsapp`.
2. [ ] להוסיף ב-Vercel: `WA_TOKEN`, `WA_PHONE_ID`, `WA_TEMPLATE`=`wedding_rsvp`, `WA_LANG`=`he`, `WA_VERIFY_TOKEN`, `WA_APP_SECRET`. ‏Redeploy.
3. [ ] לחכות שהתבנית תאושר (Meta > Message Templates > Status: Active).
4. [ ] **בדיקה על עצמכם בלבד**: להוסיף את עצמכם לרשימת המוזמנים (אם אתם לא שם) ולפתוח
   `https://<האתר>/api/send-whatsapp?key=<ADMIN_KEY>&only=<הטלפון שלך>`
   - לענות "מגיעים", לבחור כמות ומנה, ולוודא שהשורה שלכם בגיליון התעדכנה (ערוץ "וואטסאפ").
   - לנקות אחר כך את הסטטוס ואת "וואטסאפ נשלח" בשורה שלכם.

### שלב 5: מוקד השיחות wedding-call (שעה-שעתיים)
1. [ ] להכניס את השינויים מהענף `claude/secure-sheets` של wedding-call ל-AI Studio, או לפרוס את הענף ל-Cloud Run.
   אם AI Studio שומר ל-GitHub, השמירה הבאה שלו עלולה לדרוס את התיקונים. תבדקו שהם נשארו.
2. [ ] Twilio: לפתוח חשבון ולקנות מספר. מספר ישראלי דורש מסמכים (כמה ימים).
3. [ ] משתנים (AI Studio > Secrets): `ALLOWED_EMAILS` (המייל שלך), `SERVER_SECRET` (מחרוזת אקראית), `SHEET_URL`, `SHEET_SECRET` (אותם ערכים כמו בשלב 3), `APP_URL`, `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM_NUMBER`. פירוט ב-README של wedding-call.
4. [ ] בממשק: **הגדרות האירוע** > לתקן ל"עידו ותאיר", "יום שני, 28.06.2027", "סופיה, יצחק סלמה 1, באר שבע" (האירוע השמור עדיין עם "עידו ונועה").
5. [ ] **סימולטור**: לדבר עם הסוכן בעברית. לנסות שמות קשים מהרשימה ותשובות כמו "אנחנו בערך שלושה", "אחד טבעוני".
6. [ ] **שיחה אמיתית אחת למספר שלך**: מסך הטלפוניה > שיחה יוצאת > Twilio. לוודא שהשורה שלך בגיליון התעדכנה (ערוץ "שיחה").

### שלב 6: הפעלה על האורחים
1. [ ] וואטסאפ בקבוצות: `.../api/send-whatsapp?key=<ADMIN_KEY>&dry=1` כדי לראות, ואז `...&limit=50`. לחזור עד שכולם קיבלו.
2. [ ] לחכות 48 שעות. בינתיים לעקוב בגיליון (אפשר לסנן לפי "סטטוס").
3. [ ] wedding-call > **שיחות לאורחים מגוגל שיטס** > "תצוגה מקדימה", ואז "להתקשר עכשיו" עם 10 שיחות. לבדוק בגיליון שהתשובות נכנסו, ורק אז להמשיך בקבוצות.
4. [ ] מי שנשאר בלי תשובה אחרי 3 ניסיונות: להתקשר ידנית.

### שלב 7: לפני החתונה
- [ ] ספירה סופית: לסכם את "כמות מאושרת" ולספור מנות צמחוניות/טבעוניות לאולם.
- [ ] גיבוי: קובץ > הורדה > Microsoft Excel.
- [ ] אחרי החתונה: לבטל את מספר Twilio ואת המנויים, ולמחוק את המפתחות מ-Vercel ומ-AI Studio.

## עזרה
- **`unauthorized`**: `ADMIN_KEY` בכתובת לא נכון, או ש-`SHEET_SECRET` שונה מ-`SECRET` ב-Script Properties.
- **`חסר משתנה סביבה`**: להוסיף ב-Vercel ולעשות Redeploy.
- **תשובות לא נכנסות לגיליון**: לפתוח את קישור הבדיקה משלב 2.6 ולראות מה הוא מחזיר.
- לוגים: Vercel > Project > **Logs**.
- הוראות מפורטות לוואטסאפ: [`docs/rsvp-automation.md`](docs/rsvp-automation.md).

## מבנה הריפו
- `index.html`, `assets/`: האתר (סטטי, בלי build).
- `api/`: פונקציות Vercel לוואטסאפ (`send-whatsapp.js`, `whatsapp.js`).
- `rsvp-apps-script.gs`: הקוד של Apps Script (להדביק בגיליון "מוזמנים לחתונה").
- `docs/rsvp-automation.md`: הוראות מפורטות.
