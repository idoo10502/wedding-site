# אישורי הגעה אוטומטיים: וואטסאפ + שיחת AI

**איך זה עובד**
1. רשימת המוזמנים יושבת בגיליון **"רשימת מוזמנים - חתונה עידו ותאיר"** בגוגל דרייב, באותו מבנה כמו קובץ האקסל (לשונית לכל קבוצה).
   המערכת מוסיפה בסוף כל לשונית את העמודות: `סטטוס | כמות מאושרת | מנה | ערוץ | וואטסאפ נשלח | ניסיונות שיחה | עודכן | הערות`, ולא נוגעת בעמודות הקיימות (כולל "לא לגעת").
   רק שורות עם טלפון נכנסות לתהליך.
2. `/api/send-whatsapp` שולח לכל אורח הודעה עם 2 כפתורים: "מגיעים", "לא נוכל להגיע".
   מי שהוזמן עם יותר מאדם אחד מקבל רשימה לבחירת כמות (עד מספר המוזמנים בעמודה "מוזמנים"),
   ואז שאלה על מנה: רגילה, צמחונית או טבעונית. כל תשובה נכתבת לגיליון.
3. אחרי 48 שעות, מוקד השיחות (ריפו **wedding-call**, ‏Gemini Live + Twilio) מתקשר למי שלא ענה, שואל את אותן שאלות,
   וכותב את התשובות לאותו גיליון. ההגדרות שם ב-README.

אישורים מהאתר ממשיכים להיכנס ללשונית "אישורי הגעה" כמו קודם. אם האורח מילא טלפון שנמצא ברשימת המוזמנים, הוא מסומן גם שם (ערוץ "אתר"), ולכן לא יקבל וואטסאפ ולא שיחה.

---

## שלב 1: הגיליון (10 דקות)
1. מעתיקים את `rsvp-apps-script.gs` ל-Apps Script של גיליון **אישורי ההגעה** (אותו פרויקט שכבר קיים) ושומרים.
   מזהה גיליון המוזמנים כבר כתוב בקוד (`GUESTS_SPREADSHEET_ID`).
2. **Project Settings** (גלגל השיניים) > **Script Properties** > **Add**: שם `SECRET`, ערך: מחרוזת אקראית ארוכה (למשל מ-passwordsgenerator.net, 40 תווים).
3. בעורך בוחרים בפונקציה **`testGuests`** ולוחצים **Run**. גוגל יבקש הרשאה לגשת לגיליון המוזמנים: מאשרים.
   ב-Execution log אמור להופיע "אורחים עם טלפון: 343".
4. **Deploy > Manage deployments > עיפרון > Version: New version > Deploy**. הכתובת לא משתנה.
5. אורחים חדשים מוסיפים ישירות בגיליון המוזמנים, בכל לשונית שיש בה "שם מלא" ו"טלפון".
   מספר שעונה ולא נמצא ברשימה נרשם בלשונית "לא ברשימה".

## שלב 2: וואטסאפ (Meta WhatsApp Cloud API, 30-60 דקות + אישור תבנית)
1. developers.facebook.com > **Create App** > סוג **Business** > מוסיפים את המוצר **WhatsApp**.
2. מחברים מספר טלפון ייעודי (מספר שלא פעיל באפליקציית וואטסאפ רגילה). לבדיקות יש מספר ניסיון חינמי.
3. יוצרים **System User** עם הרשאת `whatsapp_business_messaging` ומפיקים **טוקן קבוע** (הטוקן הזמני פג אחרי 24 שעות).
4. **Message Templates > Create**: קטגוריה **Utility**, שם `wedding_rsvp`, שפה **Hebrew**:
   ```
   שלום {{1}},
   עידו ותאיר מתחתנים ושמחים להזמין אתכם 💍
   יום שני, 28.06.2027 | ״סופיה״, יצחק סלמה 1, באר שבע
   קבלת פנים 19:30 | חופה 20:30
   נשמח לדעת אם תגיעו:
   ```
   `{{1}}` = השם המלא מהעמודה "שם מלא" (למשל "בר וליטל לסרי").
   כפתורי **Quick reply** (בדיוק בטקסט הזה): `מגיעים` · `לא נוכל להגיע`
5. **Configuration > Webhook**:
   - Callback URL: `https://<הדומיין-שלכם>/api/whatsapp`
   - Verify token: מחרוזת שאתם בוחרים (אותה מכניסים ל-`WA_VERIFY_TOKEN`)
   - מסמנים **messages** ב-Webhook fields.

**עלות**: הודעת Utility בישראל בערך 0.5-1 סנט עד כמה סנטים להודעה (תלוי במחירון Meta העדכני). תשובות האורחים בתוך 24 שעות חינמיות.

## שלב 3: שיחות AI
עברו לריפו **wedding-call** (מוקד שיחות עם Gemini Live + Twilio). ההגדרות ב-README שלו.
משתמשים שם באותם `SHEET_URL` ו-`SHEET_SECRET` כמו כאן.

## שלב 4: משתני סביבה ב-Vercel
**Settings > Environment Variables**, ואחרי זה **Redeploy**:

| שם | ערך |
|---|---|
| `ADMIN_KEY` | סיסמה שאתם בוחרים, להפעלת השליחה והשיחות |
| `SHEET_URL` | כתובת ה-`/exec` של Apps Script |
| `SHEET_SECRET` | אותו ערך כמו `SECRET` ב-Script Properties |
| `WA_TOKEN` | הטוקן הקבוע של Meta |
| `WA_PHONE_ID` | Phone number ID מעמוד WhatsApp > API Setup |
| `WA_TEMPLATE` | `wedding_rsvp` |
| `WA_LANG` | `he` |
| `WA_VERIFY_TOKEN` | המחרוזת שבחרתם בשלב 2.5 |
| `WA_APP_SECRET` | App Secret מ-App settings > Basic (מאמת שההודעות באמת מ-Meta) |

## שלב 5: הפעלה
פותחים בדפדפן (מחליפים `KEY` ב-`ADMIN_KEY`):

| מה | כתובת |
|---|---|
| מי יקבל וואטסאפ (בלי לשלוח) | `/api/send-whatsapp?key=KEY&dry=1` |
| שליחת וואטסאפ | `/api/send-whatsapp?key=KEY` |

- **לבדוק קודם על עצמכם**: לשים בגיליון רק את השורות שלכם, לשלוח, לענות, ולראות שהגיליון מתעדכן.
- שיחות לאורחים שלא ענו מפעילים מהממשק של wedding-call (טלפוניה > שיחות לאורחים מגוגל שיטס).

## בעיות נפוצות
- **`unauthorized`**: `ADMIN_KEY` בכתובת לא תואם, או `SHEET_SECRET` שונה מ-`SECRET` בסקריפט.
- **`חסר משתנה סביבה`**: הוסיפו אותו ב-Vercel ועשו Redeploy.
- **וואטסאפ לא נשלח, `Template name does not exist`**: התבנית עוד לא אושרה, או שהשם/השפה לא תואמים.
- **תשובות מוואטסאפ לא נכנסות לגיליון**: Webhook לא מאומת ב-Meta, או ש-`messages` לא מסומן.
- **הטלפון בגיליון בלי 0 בהתחלה**: תקין, המערכת מסתדרת עם זה.
- לוגים: Vercel > Project > **Logs**.
